## 大小写冲突风险

- `EXDEF.h → point.h`：需确认不与 `game/coords.h` 的 `POINT_*` 冲突
- `GIAN.h → gian.h`：Windows 不区分大小写，需 `git mv` 分两步或使用临时名
- Windows 文件系统默认不区分大小写，在 Linux CI 上会区分

## 验证

- 每个子目录 PR 后：`./build_windows.bat`
- Linux 构建（如适用）：`./build_linux.sh`
