# AGENTS.md

## Build

```bash
# Prerequisites: Visual Studio 2022+, Git, CMake 3.21+, Ninja
./build_windows.bat
# Output: build/bin/GIAN07.exe + build/bin/SDL3.dll
```

## Architecture

- **`GIAN07/`** — Original pbg game code (~2000 era, 8.3 filenames, `*.CPP` extensions)
- **`game/`** — Modern platform-independent layer (graphics, audio, input abstractions)
- **`platform/`** — Platform backends. Game code should only include headers from `platform/` itself, not from subdirectories.
  - `platform/sdl/` — SDL3 backend (used on both Windows and Linux)
  - `platform/windows/` — Win32-native: GDI text, WinMM MIDI, file I/O
  - `platform/miniaudio/` — Audio via miniaudio single-header lib (`miniaudio.c` compiled as C++)
- **`libs/`** — Git submodules for vendored dependencies

## Important constraints

- **No C++20 Modules** — Removed from the project; CMake does not enable modules.
- **No win98/vintage support** — All `WIN32_VINTAGE`, `__WIN9X__` code paths and `platform/windows_vintage/` have been removed.
- **SDL3 fork** — Uses `nmlgc/SDL` (branch `SDL3_win9x`), not upstream libsdl-org/SDL.
- **Generated headers** — `obj/version.h` and `obj/platform_constants.h` are generated by CMake at configure time via git info and environment variables (`APP_ID`, `PATH_SKELETON`). Do not edit them directly.
- **miniaudio** — Compiled via `platform/miniaudio/miniaudio.c` which `#include`s the submodule's single-file implementation. Flags in `platform/miniaudio/flags.h`.

## Platform notes

- Windows (MSVC) is the primary target. Linux support exists in CMake but may need system packages (pangocairo, fontconfig).
- SDL3 on Windows is built as a shared library (DLL) from the submodule.
- BLAKE3, libogg, libvorbis, libwebp_lossless are built as static libraries.
- dr_libs is header-only.
